# Калькулятор FEFCO

Развёртки и объёмная сборка коробок по внутренним размерам и толщине картона в миллиметрах.

- **0427** — почтовая с закатными торцами: двойная биговка закатки, ушки крышки и клапана в боковые карманы, язычки в прорези дна
- **0422** — лоток: двойные длинные стенки, косынки, крючки язычков в прорезях дна
- **0470** — обёртка без клея: ушки и клапан крышки заправляются внутрь, язычок в кромку
- **0471** — обёртка с прорезями в торцах: скруглённый клапан и крючки в эти прорези
- **0215** — склеенный рукав, дно 1-2-3 и полная крышка на длинной стороне
- **0201** — четырёхклапанный рукав: сначала малые клапаны, затем большие сверху

Размеры Д, Ш, В и толщина *t* задают геометрию через каскад параметров (override → derived → default): tuck clearance, ширина прорезей, girth на обечайке 0201/0215, мостик двойной биговки 0427. 0427, 0422, 0470 и 0471 собираются с плоского листа. 0201 и 0215 показывают уже сформированный рукав.

Полные flute-таблицы производства (δ из d0427) и каталожная ленточная топология blank 0427 ещё не подключены — см. gaps в PR. Скачанный SVG — чертёж реза и биговки 1:1, не готовый штамп.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4317](http://localhost:4317).

Проверка фаз сборки:

```bash
npm run check:folds
```
