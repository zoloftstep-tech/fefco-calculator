# Калькулятор FEFCO

Развёртки и объёмная сборка коробок по внутренним размерам в миллиметрах.

- **0427** — самосборный лоток с откидной крышкой и язычком
- **0422** — самосборный лоток: торцы, ушки и замки
- **0201** — четырёхклапанный рукав, закрытие малых и больших клапанов

Размеры Д, Ш и В задают геометрию. Анимация собирает самосборную коробку с плоского листа в том же масштабе. Линейка на макете показывает миллиметры текущего вида.

Геометрия идеализированная, score-to-score: без толщины картона, ширины прорезей и производственных зазоров. Скачанный SVG — чертёж реза и биговки 1:1, не готовый штамп.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4317](http://localhost:4317).
