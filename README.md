# Калькулятор FEFCO

Развёртки и объёмная сборка коробок по внутренним размерам в миллиметрах.

- **0427** — почтовая с закатными торцами: ушки крышки и ушки клапана заходят в боковые стенки, язычки в прорези дна
- **0422** — лоток: двойные длинные стенки, косынки, крючки язычков в прорезях дна
- **0470** — обёртка без клея: ушки и клапан крышки заправляются внутрь, язычок в кромку
- **0471** — обёртка с прорезями в торцах: скруглённый клапан и крючки в эти прорези
- **0215** — склеенный рукав, дно 1-2-3 и полная крышка на длинной стороне
- **0201** — четырёхклапанный рукав: сначала малые клапаны, затем большие сверху

Размеры Д, Ш и В задают геометрию. 0427, 0422, 0470 и 0471 собираются с плоского листа. 0201 и 0215 показывают уже сформированный рукав. Линейка на макете — те же миллиметры, что в полях. Кнопки и колёсико на модели отдаляют и приближают сборку.

Геометрия score-to-score: без толщины картона, ширины прорезей и производственных зазоров. Скачанный SVG — чертёж реза и биговки 1:1, не готовый штамп.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4317](http://localhost:4317).
