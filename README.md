# Калькулятор FEFCO

Развёртки и объёмная сборка коробок по внутренним размерам в миллиметрах.

- **0427** — почтовая с закатными торцами: язычки в дно, крышка и клапан за переднюю стенку
- **0422** — лоток: двойные длинные стенки, косынки на торцах, язычки в прорези дна
- **0470** — обёртка без клея: ушки, внутренняя кромка переда и язычок крышки
- **0215** — склеенный рукав, дно 1-2-3 и полная крышка на длинной стороне
- **0201** — четырёхклапанный рукав: сначала малые клапаны, затем большие сверху

Размеры Д, Ш и В задают геометрию. 0427, 0422 и 0470 собираются с плоского листа. 0201 и 0215 показывают уже сформированный рукав. Линейка на макете — те же миллиметры, что в полях.

Геометрия score-to-score: без толщины картона, ширины прорезей и производственных зазоров. Скачанный SVG — чертёж реза и биговки 1:1, не готовый штамп.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4317](http://localhost:4317).
