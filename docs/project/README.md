# Материалы проекта

Заметки, по которым собраны развёртка и порядок фальцовки шести кодов FEFCO. Служебная разметка из рабочих черновиков убрана.

| Файл | Содержание |
| --- | --- |
| `merge-context.md` | Контекст слияния: что уже было в калькуляторе и что переносилось |
| `fefco-types-research.md` | Реальный порядок сборки 0201, 0215, 0422, 0427, 0470, 0471 |
| `opus-handoff.md` | Заметки по геометрии каталога, без кода |
| `opus-handoff-review.md` | Ревью посадки после коммита `0ca5bd8` |
| `fefco-merge-gaps.md` | Что на момент ревью ещё не было закрыто |
| `open-dieline-recalc-principles.md` | Принципы пересчёта из open-dieline |
| `d0427-formula-extract.md` | Формулы и топология генератора d0427 |
| `opus-refs/` | Каталожные PNG, параметры Essential Image и замеры 0470/0471 |

В тексте документов ещё встречаются пути `internal/` и `docs/` из исходных черновиков. В этом репозитории те же файлы лежат в `docs/project/`.
